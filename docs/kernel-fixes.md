## 同时完成的改进

- 调色板采样直接 seek，减少不必要的 raw 文件扫描；有损关闭时映射复用原像素切片。
- 少量精确颜色直接保留，修复相近颜色被单个 5-bit bin 合并的问题；查找表的精确色修正也支持同一查找单元内的相近颜色。
- Wu 分裂比较三条轴，跳过空切分；质量 1 不再构建无用的 Lloyd 查找表，最后一次迭代后也不再重复构建。
- 过期的后台估算可以取消并丢弃，正式导出排队时先取消旧估算；前端的预计帧数使用内核实际采样率。
- JSON 解析器限制嵌套深度，拒绝非法代理对、非有限数值与尾部垃圾；修正未使用的 DataFile 构造接口和 RGBA 字节注释。
- 不稳定的多线程耗时断言移为单独手动性能基准，普通测试仍验证多线程输出一致。

## 接口与行为变化

ABI 从 6 升级为 **7**，前端与内核需一起重建。C options 的 `dither_strength=0` 现在明确关闭抖动，默认强度应设为 100；Rust `Default` 与空 options 指针保持默认强度。增加 `GIF_ERR_CANCELLED=-8`、`GIF_ERR_BUSY=-9`，以及考虑 speed 的帧数查询 `gif_estimate_frames_ex`。

`GifCoreExportResult.duration` 现在是实际 GIF 播放秒数，`fps` 为实际写出帧数除以播放秒数。高帧率与高速度组合可能减少采样帧数，以维持速度与播放器兼容延时。延时、调色板和算法修正意味着不能承诺与旧版导出逐字节相同；同版本的不同线程数仍保持一致。

FFI 借用缓冲区要求调用方在重建/关闭/加载前完成复制，销毁 handle 前须等待所有调用结束。Rust 指针接口使用 unsafe 表达此契约；C++ 当前调用方式符合这一约定。

## 验证与剩余优化

新增正式测试位于 `tests/kernel_regressions.rs` 与对应模块的单元测试中，素材运行时生成；工具缺失会明确失败。`tests/support/media_tool.rs` 为测试用异常子进程，不随产品打包。

最终验证环境：Windows，Rust 1.99.0 GNU 工具链，FFmpeg 8.1，Qt 6.10.2 MinGW。
