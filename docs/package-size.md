# Easy2GIF 命名与包体优化

日期：2026-10-15。体积单位采用 MiB（1 MiB = 1,048,576 字节）。

## 命名

CMake 工程与目标、QML 模块、可执行文件、CLion 运行配置、构建/部署脚本及文档
统一使用 `easy2gif`。界面品牌为 Easy2GIF，发布入口为 `easy2gif.exe`。
Rust 内核 `gifcore` 与开发启动器 `forge.exe` 保留各自职责和名称；主题设置位置
不变，已有深浅色偏好继续有效。

## 已实现的优化

1. 发布版链接时去除最终可执行文件的符号表，主程序从 6,883,146 字节降到
   1,650,176 字节。
2. FFmpeg 和 FFprobe 改用固定版本的共享库发行包，两者共用媒体 DLL。
   媒体运行时从 201,913,344 字节降到 167,596,544 字节（不含文本清单）。
   下载脚本校验固定 SHA256，并只提取两个工具、必要 DLL 和许可证。
3. 清除未使用的 Qt Quick Controls 样式、调试与未使用的插件，保留固定使用的
   Basic 样式；加入 `qt.conf`，让运行时从发布目录解析依赖。
4. 增加可复现的打包脚本，使用全新暂存目录、媒体运行时清单、源码版本信息，
   附带许可证与 SHA256。ZIP 以当前 .NET 支持的最高 Deflate 压缩级别生成，
   可额外输出 7z。

## 实测

| 项目 | 上一版 | 本次优化 |
| --- | ---: | ---: |
| ZIP | 107.64 MiB | 97.00 MiB |
| 7z（额外提供） | — | 71.58 MiB |
| 解压后的文件总大小 | 287.02 MiB | 242.34 MiB |
| 主程序 | 6.56 MiB | 1.57 MiB |

ZIP 减少约 9.9%，解压体积减少约 15.6%；7z 比上一版 ZIP 小约 33.5%。
许可证与构建时间等元数据会造成少量差异。

验证覆盖：共享版媒体工具下 90 项自动测试通过，2 项手工性能测试按默认配置忽略；
ZIP CRC 校验通过；解压后清理 PATH 与 Qt/媒体环境变量，验证原生界面、软件渲染、
导入、导出、打开/保存目录对话框以及 Rust 启动器。H.264 测试视频成功导出 320×240、60 帧、5 秒的 GIF，
使用包内 FFprobe 独立回读核对。

## 还能进一步压缩的方向

- 自行构建只保留解码、探测、缩放和原始帧输出功能的 FFmpeg，可继续显著减少
  媒体运行时；需要维护编译链，并覆盖 H.264、HEVC、AV1、VP9、常见容器和损坏
  输入的回归测试。当前采用通用共享发行版，避免未经验证地裁掉输入格式支持。
- `opengl32sw.dll` 约 19.7 MiB，是继续裁剪 Qt 时的大项。本次保留软件渲染回退
  与 D3D 编译组件，以兼容老显卡、远程桌面等环境。
- 7z 通常比 ZIP 更小，适合下载分发；会增加打包耗时，且需要支持 7z 的解压工具。
  ZIP 同时保留，便于 Windows 直接解压使用。
- 暂不使用 UPX 等可执行文件加壳方式，以免引入杀毒误报、启动开销和排查难度。

共享媒体版本与下载校验值见 `tools/get-shared-ffmpeg.ps1`，复现命令：

```powershell
.\package.ps1 -SharedMedia -SevenZip
```
